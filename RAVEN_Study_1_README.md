# RAVEN Study 1: Predictions and Explanations for Abstract Visual Reasoning

This repository contains the materials, model code, stimuli, anonymized interaction logs, and analysis notebooks for the first RAVEN experiment. The study examined how an AI prediction and two forms of explainable AI (XAI) support affected participants' answers and confidence on abstract visual reasoning problems.

The two explanation conditions were:

1. **LLM explanation:** a prediction and natural-language explanation generated by Claude.
2. **Occlusion Sensitivity (OS):** a prediction generated by a DCNet model and a visual heatmap showing image regions that influenced the model's output.

## Source and attribution

The DCNet implementation was adapted from the original DCNet repository:

https://github.com/visiontao/dcnet

The files required to inspect and run the model, including the DCNet architecture and the selected trained weights, are included in this repository. It is therefore not necessary to clone the original repository to reproduce the inference examples provided here.

## Obtaining the full RAVEN-10K dataset

The repository includes the RAVEN instances required for inspecting and reproducing the experimental stimuli. The complete RAVEN-10K dataset is not redistributed in this archive.

To retrain or evaluate DCNet on the complete dataset, download RAVEN-10K from:

https://wellyzhang.github.io/project/raven.html#dataset

After downloading the archive, extract it before running the training or evaluation scripts.

By default, `train.py` expects the complete dataset under:

dataset/RAVEN-10000/


## Study procedure

Participants completed 16 RAVEN-style matrix reasoning problems, divided into two blocks of eight problems. One block used LLM explanations and the other used Occlusion Sensitivity explanations; the block order varied across participants.

Each trial contained three reveal stages:

1. **Before AI:** the participant selected an answer and rated their confidence without AI assistance.
2. **After AI prediction:** the AI prediction was displayed, after which the participant could revise the answer and confidence rating.
3. **After XAI explanation:** either a textual LLM explanation or an Occlusion Sensitivity heatmap was displayed, after which the participant could revise the answer and confidence rating again.

Participant confidence was recorded on a 1–5 scale. Trial-level confidence of the AI model was not required for the RAVEN Study 1 analysis and was not presented as a separate experimental variable.

## Models and explanation methods

### LLM condition

The textual predictions and explanations were generated using **Claude 3.7** through its conversational interface.

The base prompt is preserved in `participant_materials/prompt.rtf`:

> Here is a question from the RAVEN-10k dataset and the choices. Please provide an explanation to the best choice to your opinion and provide 3-4 rows of the logic behind.

The puzzle matrix and answer choices were supplied with the prompt. Because the conversational interface was used rather than an API, generation parameters such as temperature, top-p, top-k, random seed, and maximum token count were not manually configured or recorded.

The LLM prediction and the corresponding textual explanation came from the same LLM response.

### DCNet and Occlusion Sensitivity condition

The OS condition used a PyTorch implementation of **DCNet**, defined in `dcnet.py`. The trained weights are stored in:

```text
model_new_04.pth
```

For each problem, DCNet produces eight output logits, one for each answer choice. The predicted answer is the index with the largest logit.

Occlusion Sensitivity explanations were generated by repeatedly masking local image regions and measuring the change in the score of the model's predicted class. The implementation is included in `generate_data.ipynb`. In the provided implementation, the default occlusion window is 20 pixels and the stride is 10 pixels. The resulting sensitivity maps are normalized and overlaid on the original grayscale panels and answer choices.

The DCNet prediction and the OS heatmap therefore originate from the same model pipeline.
